# 狩猟免許 試験対策

ブラウザだけで動く、狩猟免許の知識試験対策アプリです。サーバーもインストールも不要です。網猟・わな猟・第一種銃猟・第二種銃猟の4種類に対応しています。

## できること

- **1000問**の三肢択一。免許ごとに、共通の法令・鳥獣・保護管理と、その猟具を出します
- **模擬試験**は30問・90分。法令13、猟具6、鳥獣9、保護管理2。21問以上で合格表示
- どのモードでも、1問答えるごとに正誤と解説を表示します
- **一部免除**は猟具10問・30分
- **間違えた問題**は、次に正解するまでやり直しに残ります
- **項目別の成績**は、受けた問題だけの正答率とやり直し待ちを集計し、JSONで書き出せます

## 使い方

1. このフォルダの `index.html` をブラウザで開く  
   または、フォルダ内で次を実行して `http://127.0.0.1:8765/` を開く

```powershell
python -m http.server 8765
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で **Deploy from a branch** を選び、`main` の `/`（root）を指定します。公開後の入口は `index.html` です。

解答の記録は GitHub ではなく、使っているブラウザにだけ保存されます。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | 入口 |
| `app.js` / `styles.css` | 画面 |
| `logic.js` | 出題・採点・成績 |
| `questions.js` | 1000問 |
| `build_questions.py` / `facts.txt` | 問題データの生成 |
